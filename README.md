# 🏷 Survey Form Project

> A responsive survey form built with HTML and CSS that collects user feedback through a clean and user-friendly interface.

---

## 📌 Problem Statement

Many beginner web developers struggle to practice real-world form design and responsive layouts. This project helps demonstrate how surveys and data collection forms can be designed using only HTML and CSS while maintaining accessibility and responsiveness.

---

## 🎯 Project Goals

* Build a responsive survey form interface
* Practice HTML form structure and semantics
* Improve CSS styling and layout skills
* Create a clean and user-friendly UI
* Learn form input organization and validation basics

---

## 🛠 Tech Stack

**Frontend:**

* HTML5
* CSS3

**Other Tools:**

* Git & GitHub
* VS Code

---

## 🖥 Features

* Responsive form layout
* Multiple input fields
* Radio buttons and checkboxes
* Dropdown selection menu
* Textarea for user feedback
* Clean and modern design
* Mobile-friendly interface

## ⚙ Installation & Setup

### 📥 Clone the repository

```bash
git clone git@github.com:Hache-premier/Survey_Form.git
cd Survey_Form
```

---

### ▶ Run the project

You can open it in your browser in two ways:

**Option 1: Direct open**

* Open the `index.html` file in your browser

**Option 2 (Recommended): Live Server**

* Install the **Live Server** extension in VS Code
* Right-click `index.html`
* Click **“Open with Live Server”**
